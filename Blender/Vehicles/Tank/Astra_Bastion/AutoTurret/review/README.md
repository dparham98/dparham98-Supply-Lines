# Bastion close-defence range

Extract the ZIP to an empty folder outside Supply Lines. Open its `project.godot` with Godot 4.7.2 and press **F5**.

The Bastion's main cannon is directed at the far infantryman. The roof turret chooses the nearest hostile unit within its own range and fires short, copper-tipped bullets. Each bullet travels to the point the turret fired at. Move the target while the bullet is in flight to make it miss. The infantrymen are reusable range targets, and the counters show shots fired.

| Input | Action |
| --- | --- |
| Click ground | Move the near target to a new bearing or distance |
| Space | Move the near target across the 10 m engagement limit |
| Tab | Switch between the range and a close view of the turret |
| H | Hide or show the controls |
